Fundamentos de JS

O que são Objetos em JavaScript?

Em JavaScript, um Objeto é uma coleção de pares de chave: valor. Enquanto variáveis simples guardam apenas um valor por vez (ex: uma string ou número), objetos permitem agrupar dados complexos e funcionalidades relacionadas sob uma única estrutura.

Chaves (Propriedades)

Identificadores (strings ou Symbols) que dão nome aos dados armazenados.

Valores Variados

Podem ser números, strings, booleanos, arrays, outros objetos ou funções.

Tipo de Referência

Objetos são alocados na memória por referência, e não por cópia de valor direto.

2. Criação, Leitura e Modificação

Notação Literal `{}`

A forma mais comum de criar objetos em JS é usando a notação literal. Para acessar e modificar propriedades, usamos a notação de ponto (`.`) ou a notação de colchetes (`[]`).

Notação de Ponto (`.`)

Sintaxe mais limpa e direta. Ideal quando você já sabe o nome exato da propriedade.

pessoa.nome = 'Maria';

Notação de Colchetes (`[]`)

Permite usar variáveis para acessar chaves dinâmicas ou chaves com caracteres especiais/espaços.

pessoa['primeiro nome'] ou pessoa[chaveVariavel]
Exemplo Prático: Criando e Manipulando um Carro

Código JavaScript:

const carro = {
  marca: 'Toyota',
  modelo: 'Corolla',
  ano: 2022,
  cor: 'Prata'
};

// Adicionando nova propriedade
carro.ligado = true;

// Acesso dinâmico com colchetes
const propriedadeBuscada = 'modelo';
const valorModelo = carro[propriedadeBuscada];

// Deletando uma propriedade
delete carro.cor;

3. Métodos e a Palavra-chave `this`

Funções internas

Quando uma função é armazenada dentro de uma propriedade de um objeto, ela é chamada de método. Dentro do método, a palavra-chave this faz referência ao próprio objeto em que o método foi chamado.

Cuidado com Arrow Functions!

Arrow Functions (() => {}) não possuem seu próprio contexto de `this`. Se você definir um método usando arrow function, o `this` herdará o escopo externo (normalmente `window` ou `undefined`), e não o objeto!

Exemplo Prático: Conta Bancária com Métodos

Código JavaScript:

const contaBancaria = {
  titular: 'Ana Silva',
  saldo: 500,

  // Método tradicional (sintaxe reduzida ES6)
  depositar(valor) {
    this.saldo += valor;
    return `Depósito de R$${valor} realizado. Novo saldo: R$${this.saldo}`;
  },

  exibirResumo() {
    return `Titular: ${this.titular} | Saldo: R$${this.saldo}`;
  }
};

4. Métodos Utilitários do Construtor Object

Object.keys(), Object.values(), Object.entries()

O JavaScript fornece vários métodos estáticos no objeto global Object para inspecionar, converter e proteger objetos.

Inspecionando Conteúdo

  • Object.keys(obj): Retorna um array com todas as chaves.
  • Object.values(obj): Retorna um array com todos os valores.
  • Object.entries(obj): Retorna matriz de pares `[chave, valor]`.

Manipulação & Proteção

  • Object.assign(dest, src): Copia propriedades para outro objeto.
  • Object.freeze(obj): Impede alterações (torna imutável).
  • Object.seal(obj): Permite alterar valores, mas impede criar/deletar chaves.
Exemplo Prático: Iterando e Congelando Objetos

Código JavaScript:

const usuario = { id: 101, nome: 'Carlos', cargo: 'Dev' };

const chaves = Object.keys(usuario);
const valores = Object.values(usuario);
const pares = Object.entries(usuario);

// Congelando o objeto
const configuracao = Object.freeze({ tema: 'escuro' });
configuracao.tema = 'claro'; // Não terá efeito!

Recursos Modernos (ES6+)

5. Desestruturação, Spread Operator & Optional Chaining

Recursos modernos do JavaScript facilitam o trabalho com objetos no dia a dia, aumentando a legibilidade do código.

Desestruturação (Destructuring) & Operador Spread (`...`)

A desestruturação permite extrair valores de propriedades diretamente em variáveis. O operador Spread (`...`) permite clonar ou fundir objetos de forma imutável.

const perfil = { usuarioNome: 'Lucas', idade: 28, cidade: 'São Paulo' };

// Desestruturação com valor padrão e alias (renomeação)
const { usuarioNome: nome, cidade, pais = 'Brasil' } = perfil;

// Clonando e adicionando novas propriedades com Spread
const perfilAtualizado = { ...perfil, profissao: 'Engenheiro' };

Encadeamento Opcional (`?.`)

Evita erros fatais de `TypeError: Cannot read properties of undefined` ao tentar acessar propriedades aninhadas que podem não existir.

const rua = cliente?.endereco?.rua; // Retorna undefined ao invés de quebrar a aplicação!

6. Exercícios de Fixação

Teste seus conhecimentos. Tente resolver mentalmente ou no editor e clique para verificar a solução.

Exercício 1: Criar Objeto e Adicionar Método Fácil

Crie um objeto chamado livro com as propriedades titulo e autor. Em seguida, adicione um método chamado descrever() que retorne uma string formatada com essas informações.

Ver Solução 
const livro = {
  titulo: 'O Senhor dos Anéis',
  autor: 'J.R.R. Tolkien',
  descrever() {
    return `O livro "${this.titulo}" foi escrito por ${this.autor}.`;
  }
};

console.log(livro.descrever());
Exercício 2: Somar valores das propriedades com Object.values() Médio

Dado o objeto de despesas { aluguel: 1200, luz: 150, internet: 100 }, calcule o total gasto utilizando Object.values() e reduce().

Ver Solução 
const despesas = { aluguel: 1200, luz: 150, internet: 100 };

const total = Object.values(despesas).reduce((acc, valor) => acc + valor, 0);

console.log(`Total das despesas: R$ ${total}`); // Total das despesas: R$ 1450
Exercício 3: Mesclar objetos mantendo a imutabilidade Intermediário

Dado dois objetos: usuario e endereco, mescle-os em um único objeto clienteCompleto usando o operador spread sem modificar os originais.

Ver Solução 
const usuario = { id: 1, nome: 'Mariana' };
const endereco = { rua: 'Av. Paulista', cidade: 'São Paulo' };

const clienteCompleto = { ...usuario, ...endereco };

console.log(clienteCompleto);
// { id: 1, nome: 'Mariana', rua: 'Av. Paulista', cidade: 'São Paulo' }
