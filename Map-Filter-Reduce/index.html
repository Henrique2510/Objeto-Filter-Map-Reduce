Conceitos Fundamentais

Por que aprender Map, Filter e Reduce?

Antes do ES6 (ECMAScript 2015), iterar sobre arrays exigia loops tradicionais como for ou for...of. Os métodos map, filter e reduce introduziram um estilo mais **declarativo** e **funcional** para manipular coleções de dados em JavaScript.

Imutabilidade

Eles não alteram o array original. Sempre retornam novos dados ou valores.

Código Limpo

Eliminam variáveis auxiliares e contadores de controle manualmente criados.

Encadeamento

Permitem combinar transformações de forma contínua e expressiva.

Transformação 1 para 1

1. Array.prototype.map()

Retorna: Novo Array (mesmo tamanho)

O método map() percorre cada elemento do array e aplica uma função de transformação em cada um deles, retornando um novo array com os resultados. O número de itens no array resultante é sempre igual ao array original.

Analogia do Map

[ 🌽, 🥔, 🐔 ] .map( ) ➔ [ 🍿, 🍟, 🍳 ]

Sintaxe:

const novoArray = arrayOriginal.map((elemento, indice, arrayCompleto) => {
  return elemento * 2;
});
Exemplo Prático: Converter Preços para Reais (BRL)

Código JavaScript:

const produtos = [
  { nome: 'Teclado', preco: 150 },
  { nome: 'Mouse', preco: 80 },
  { nome: 'Monitor', preco: 900 }
];

// Transformando preços com desconto de 10%
const comDesconto = produtos.map(item => ({
  ...item,
  precoFormatado: `R$ ${(item.preco * 0.9).toFixed(2)}`
}));

2. Array.prototype.filter()

Retorna: Novo Array (igual ou menor)

O método filter() cria um novo array contendo apenas os elementos do array original que atendem a uma determinada condição (retornam true na função de callback).

Analogia do Filter

[ 🍿, 🍟, 🍳, 🍎 ] .filter( é_vegetal ) ➔ [ 🍟, 🍎 ]

Sintaxe:

const novoArrayFiltrado = arrayOriginal.filter((elemento) => {
  return elemento >= 18; // Retorna true para manter, false para descartar
});
Exemplo Prático: Filtrar Alunos Aprovados

Código JavaScript:

const alunos = [
  { nome: 'Ana', nota: 8.5 },
  { nome: 'Carlos', nota: 5.0 },
  { nome: 'Beatriz', nota: 7.0 },
  { nome: 'Daniel', nota: 4.5 }
];

// Filtrar apenas alunos aprovados (nota >= 7)
const aprovados = alunos.filter(aluno => aluno.nota >= 7);

Agregação / Acúmulo

3. Array.prototype.reduce()

Retorna: Valor único (Número, Objeto, Array, etc)

O método reduce() executa uma função "redutora" para cada elemento do array, resultando em um único valor de retorno. É extremamente versátil: serve para somar totais, agrupar objetos por categoria, encontrar maiores/menores valores e muito mais.

Analogia do Reduce

[ 🍿, 🍟, 🍳 ] .reduce( digestão ) ➔ 💩

Sintaxe e Parâmetros:

const resultado = array.reduce((acumulador, itemAtual) => {
  return acumulador + itemAtual;
}, valorInicial); // Importante definir o valorInicial!
Exemplo Prático: Calcular o valor total de um carrinho de compras

Código JavaScript:

const carrinho = [
  { item: 'Livro', preco: 30 },
  { item: 'Caneta', preco: 5 },
  { item: 'Mochila', preco: 120 }
];

// Somando os preços (Acumulador inicia em 0)
const total = carrinho.reduce((acc, produto) => {
  return acc + produto.preco;
}, 0);

4. Combinando Map, Filter e Reduce (Chaining)

Como filter e map retornam novos arrays, podemos encadeá-los sequencialmente para resolver problemas complexos com poucas linhas de código altamente legíveis.

Cenário de e-Commerce:

1. Filtrar apenas produtos da categoria "Eletrônicos".
2. Aplicar um imposto de 10% no preço dos eletrônicos seleccionados.
3. Calcular o faturamento total previsto desses itens.

const vendas = [
  { nome: 'TV', cat: 'Eletrônicos', preco: 2000 },
  { nome: 'Camisa', cat: 'Vestuário', preco: 100 },
  { nome: 'Fone', cat: 'Eletrônicos', preco: 300 }
];

const totalFaturamentoEletronicos = vendas
  .filter(item => item.cat === 'Eletrônicos') // [TV, Fone]
  .map(item => item.preco * 1.10) // [2200, 330]
  .reduce((acc, valor) => acc + valor, 0); // 2530

5. Exercícios de Fixação

Tente resolver mentalmente ou no seu editor e confira a solução clicando no botão.

Exercício 1: Dobrar valores com .map() Fácil

Dado o array [1, 4, 9, 16], crie um novo array com a raiz quadrada de cada número (Dica: utilize Math.sqrt).

Ver Solução 
const numeros = [1, 4, 9, 16];
const raizes = numeros.map(num => Math.sqrt(num));
console.log(raizes); // [1, 2, 3, 4]
Exercício 2: Filtrar pares com .filter() Fácil

Dado o array [12, 5, 8, 130, 44], retorne apenas os números maiores ou iguais a 10.

Ver Solução 
const numeros = [12, 5, 8, 130, 44];
const maioresQueDez = numeros.filter(num => num >= 10);
console.log(maioresQueDez); // [12, 130, 44]
Exercício 3: Agrupamento com .reduce() Intermediário

Dado uma lista de palavras ['maçã', 'banana', 'maçã', 'laranja', 'banana', 'maçã'], conte a frequência de cada fruta utilizando reduce.

Ver Solução 
const frutas = ['maçã', 'banana', 'maçã', 'laranja', 'banana', 'maçã'];

const contagem = frutas.reduce((acc, fruta) => {
  acc[fruta] = (acc[fruta] || 0) + 1;
  return acc;
}, {});

console.log(contagem); // { maçã: 3, banana: 2, laranja: 1 }
